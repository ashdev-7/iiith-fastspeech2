# Kaggle job records

`status.json` files (and the ingest log) of the jobs whose numbers the report quotes but which are not
otherwise stored in the repository: candidate filtering and split sizes (`fs2-01-ingest`), alignment and
dictionary counts and the Telugu test-voice choice (`fs2-02-data`), throughput probes and training time
(`fs2-03-train-en` v2, `fs2-03-train-te`), the diagnosis summary (`fs2-07-diagnose`), and the lexical-stress statistics (`fs2-15-stress-stats`). Copied unchanged
from the Kaggle outputs; they contain no dataset text or audio.
